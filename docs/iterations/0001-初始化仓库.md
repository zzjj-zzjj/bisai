## 结果与结论

仓库已可正常 clone / commit / push。发现并解决的环境问题：

1. 全局 `https.proxy` 指向未运行的 `127.0.0.1:7890`，导致 git 网络操作静默失败
   （`ls-remote` 返回 0 但无输出）。已在仓库级用 `direct://` 覆盖。
2. 全局 `user.name` / `user.email` 为空，不配置会导致 commit 直接失败。
   已在仓库级配置。
3. 认证由 Windows 凭据管理器（Git Credential Manager 2.7.3）提供，无需额外配置。
